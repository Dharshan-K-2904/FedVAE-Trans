# Security Policy

## Supported Versions
The project is currently supported on the `main` branch and the latest release line.

## Reporting a Vulnerability
Please do not disclose security issues publicly in the issue tracker.

Instead, report them privately via one of the following options:
- Open a private security advisory in GitHub, if available for the repository.
- Email the maintainer directly at the address listed in the repository profile or project documentation.

Please include:
- a description of the issue,
- affected versions or files,
- reproduction steps if available,
- the impact and severity assessment,
- suggested mitigation if known.

We aim to acknowledge valid reports within 5 business days and provide a remediation timeline when possible.

## Security Expectations
- Keep dependencies updated.
- Prefer pinned or reproducible builds for deployment.
- Review third-party and automation changes before release.
